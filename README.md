# Manual QA Interview Lab

Русскоязычный тренажёр для собеседований на Manual QA (Junior / Middle / Senior): микроуроки, реальные QA-ситуации, тесты, схемы и повторение.

**[Открыть тренажёр](https://safal207.github.io/manual-qa-interview-lab/)** · [Исходный код](https://github.com/safal207/manual-qa-interview-lab)

## Механика обучения

- **Ежедневный мини-урок (5–7 минут):** 3 открытых кейса + 1 тестовый вопрос, с понятным финалом занятия.
- **Активное вспоминание:** сначала самостоятельно объясните решение, затем откройте подсказку и сверьтесь с эталонным ответом.
- **Самооценка по критериям:** «не ответил / частично / уверенно»; свободные ответы **не оцениваются автоматически**.
- **Повторение по расписанию:** ориентировочные интервалы после оценки: 20 минут, 1 день или растущие интервалы от 1 до 30 дней при уверенном повторении. Это простая эвристика, не научно откалиброванная персональная модель памяти.
- **Работа над ошибками:** неверные ответы тестов попадают в отдельный набор; правильный ответ убирает их из этого набора.
- **Визуальные схемы:** короткие схемы основных процессов — жизненный цикл бага, клиент-сервер, HTTP/API, STLC, SQL, авторизация, интеграции, релизы и другие темы.
- **Мягкая мотивация:** отмечаются завершённые занятия, дни практики и реальные достижения; нет бессмысленных очков, бесконечной ленты, штрафов за пропуск или манипулятивных уведомлений.

## QA Simulator — ситуационные расследования

Четыре интерактивных сценария на 6–10 минут:

1. Возможное двойное списание после HTTP 504.
2. Ошибка `oauth_state_mismatch` после logout в установленной Android PWA.
3. WebSocket остаётся подключённым, но котировки устаревают.
4. Разница между SQL-отчётом и dashboard на уровне JOIN и бизнес-метрики.

В каждом сценарии 3 этапа: триаж, исследование, решение по риску. Выбираемые действия дают разные последствия и записи на **доске доказательств**. Затем техлид задаёт вопрос на защиту решения: пользователь пишет собственную аргументацию, раскрывает чек-лист сильного ответа и ставит **самооценку**. Итоговые баллы рассчитываются **только по выбору действий**, на основании заранее определённой рубрики «доказательства / безопасность / коммуникация», а не по свободному тексту. Прогресс и незавершённый сценарий сохраняются локально.

## Диалог с техлидом (текстовая тренировка)

Во вкладке **«Техлид»** доступны четыре кейса из QA Simulator: платежи, Android PWA/OAuth, WebSocket, SQL и бизнес-метрики.

- **4 коротких раунда** по 6–9 минут: начальная ситуация → текстовый ответ → уточняющий вопрос → самостоятельная проверка.
- Уточняющий вопрос **ветвится по обнаруженным темам предыдущего ответа**: например, «идемпотентность», «логи», «state», «cookies», «sequence ID», «JOIN». Если контекста не хватает, тренажёр попросит назвать доказательства.
- Алгоритм работает **локально, без LLM, API или сбора ответов на сервере**. Он не понимает смысл ответа так, как человек, не проверяет истинность рассуждений и не ставит автоматическую оценку свободному тексту. Его задача — выбрать содержательный следующий вопрос по распознанным словам.
- В конце: **рубрика сильного ответа**, список затронутых тем (по обнаруженным упоминаниям) и **самооценка**.
- Незаконченный диалог и до 10 завершённых сессий хранятся в `localStorage`. Можно скачать текущую стенограмму в TXT; перенос между устройствами автоматически не выполняется.
- Клавиатурная отправка — **Ctrl+Enter**, текст всегда отображается с экранированием HTML, а прогресс занятия ограничен по времени и количеству раундов.

Это вторая механика после детерминированного QA Simulator. Она полезна для тренировки речи и аргументации, но не заменяет обратную связь от реального интервьюера.

## Банк задач

- 12 разделов: теория QA, тест-дизайн, баг-репорты, SDLC/STLC, Web/DevTools, HTTP/REST/Postman, SQL, безопасность, Mobile/PWA, WebSocket/интеграции, Agile/релизы, ситуационные кейсы.
- 48 открытых заданий с эталонными ответами и рубриками.
- 24 тестовых вопроса с однозначно проверяемыми ответами и объяснениями.
- Симуляция интервью: 8 вопросов Middle/Senior, 20 минут.
- Поиск, фильтры, слабые темы, экспорт локальных результатов.

## Запуск

Клонируйте репозиторий и запустите сервер:

```bash
git clone https://github.com/safal207/manual-qa-interview-lab.git
cd manual-qa-interview-lab
python -m http.server 8000
```

Откройте `http://localhost:8000`. Можно открыть `index.html` напрямую, если рядом лежат `learning.js` и `learning.css`. Внешних библиотек, аккаунтов и сервера приложению не требуется.

## Проверки

```bash
npm test
```

CI проверяет синтаксис JavaScript, целостность банка, локальные зависимости, наличие учебного интерфейса, очереди повторения, QA Simulator и ветвящийся диалог с техлидом. Эти проверки **не заменяют** полноценный browser E2E и ручную регрессию.

## Публикация

В **Settings → Pages → Build and deployment** источник публикации — **GitHub Actions**. Workflow `Deploy GitHub Pages` обновляет сайт после push в `main`.
