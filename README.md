# Manual QA Interview Lab

Русскоязычный офлайн-тренажёр подготовки к собеседованиям Manual QA уровня Junior / Middle / Senior.

**[Открыть опубликованный тренажёр](https://safal207.github.io/manual-qa-interview-lab/)** — ссылка начнёт работать после создания репозитория и включения GitHub Pages.

## Что внутри

- 12 разделов: основы QA, тест-дизайн, баг-репорты, SDLC/STLC, Web/DevTools, HTTP/REST/Postman, SQL, авторизация и безопасность, Mobile/PWA, WebSocket/интеграции, Agile/релизы, ситуационные кейсы.
- 48 открытых вопросов с подсказками, эталонными ответами и критериями самооценки.
- 24 тестовых вопроса с автоматической проверкой и объяснением правильного ответа.
- Режим интервью: 8 случайных вопросов Middle/Senior, таймер 20 минут.
- Фильтр по темам и уровню, тренировка слабых тем, локальный прогресс.
- Работает без сервера, базы данных, внешних библиотек и регистрации.

> **Важно:** свободный ответ не оценивается нейросетью автоматически. Пользователь сравнивает его с рубрикой и сам выставляет оценку. Результаты хранятся в `localStorage` браузера.

## Быстрый старт

Откройте `index.html` в браузере — никакая установка не требуется.

Либо запустите локальный сервер:

```bash
python -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Проверки

Нужен Node.js 20+:

```bash
npm test
```

Команда проверяет синтаксис встроенного JavaScript и целостность банка вопросов (12 разделов, 48 кейсов, 24 теста, варианты и ключи ответов). Browser E2E в эту проверку не входит.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий `manual-qa-interview-lab` в аккаунте `safal207`.
2. Загрузите файлы проекта в ветку `main` (или выполните `git push`).
3. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Workflow `Deploy GitHub Pages` опубликует `index.html` на <https://safal207.github.io/manual-qa-interview-lab/>. Если запуск не начался, запустите его вручную в разделе **Actions**.

## Приватность и хранение данных

Прогресс хранится только в браузере на текущем устройстве. Встроенный экспорт JSON позволяет сохранить копию. Облачная синхронизация и серверный сбор ответов не реализованы.

## Развитие

Логичные следующие улучшения: импорт прогресса, больше практических задач и разбивка по навыкам, сохранение истории ответов, поддержка нескольких тренировочных профилей, адаптивное повторение и доступные клавиатурные сценарии.
